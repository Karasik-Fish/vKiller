# vKiller

Скрипт для обхода обфускации на базе кастомной виртуализации. 

## Описание задачи
Целевой бинарник реализует виртуализацию, где номера 2 наборов операций и набора регистров рандомизированы и зависят от значения секретного файла (`/flag`). Из-за этого статический анализ бесполезен - индексы меняются в зависимости от среды.

## Как работает скрипт
Поскольку флаг (и, соответственно, сгенерированная архитектура) статичен в рамках сервера, скрипт использует процесс как "черный ящик" и вытаскивает архитектуру по частям:

1. **Слепой перебор (Blind Probing):** Скрипт отправляет специально сформированные пейлоады и анализирует коды возврата процесса (например, успешное завершение, падение или SIGKILL `-9`).
2. **Поиск регистров и функций:** Сначала скрипт находит инструкции изменения регистров, затем вычисляет адрес функции-переходника, которая в себе содержит уже вызовы функций read, write, exit и тд.
3. **Chain:** Вычислив нужные индексы для интересующих функций, скрипт динамически собирает цепочку `read -> open -> read -> write`.
4. **Финальный брутфорс:** Осуществляется небольшой перебор оставшихся неизвестных параметров, после чего скрипт успешно читает флаг.
